# 规格
**总容量**：64Mbit=8MB
**块**：128个块，每块64kb
**扇区**：2048个扇区，每个扇区4kb，
	**页** ：32768页，每页256字节

# 特点
**flash存储器**写入时只能写0，不能写1。1是靠擦除实现的。所以flash写之前要先擦除。
# 常用命令
- **0x05**:读取状态寄存器，查询BUSY状态位命令
 ![Pasted image 20240408151926](../../../../uploads/stm32-hal-library/pasted-image-20240408151926.png)
- **0x06**：写使能
- **0x20**：擦除一个扇区
- **0x02**：写入一页数据256字节
- **0x03**：读取数据
