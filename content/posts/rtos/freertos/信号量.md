# 1.简介
FreeRTOS中的信号量是一种用于任务间同步和资源管理的机制，信号量可以是二进制的（0，1）也可以是计数型的（任意正整数），信号量的基本操作包括“获取”和“释放”。

# **2.信号量与队列的异同**
- *队列*：

	- 队列是一种用于任务间传递数据的机制。
	- 它允许任务按照先进先出（FIFO）的顺序共享数据。
	- 队列能够存储一定数目、大小固定的数据项目。
	- 队列特性主要有：FIFO，向队列中发送数据叫入队，从队列中读取数据叫出队。
	- 支持值传递和引用传递，值传递时是将原数据拷贝到队列中，原数据可以删除或覆写。
	- 多任务访问，不属于某个特定任务，属于公共资源。

- *信号量*：

	- 信号量是一种用于任务间同步和互斥的机制。
	- 它可以用于保护共享资源、限制并发访问、控制任务的执行顺序等。
	- 信号量具有两种类型：二值信号量和计数型信号量。
	- 用信号量可以实现任务间通信，和任务之间的同步或临街资源的互斥访问。
	- 信号量是一个非负整数，所有获取它（为了使用资源）的任务都将会减一，当该整数值为0时，所有试图获取它的任务都处于阻塞状态。

> **总的来说信号量是一种特殊的队列**（杀鸡焉用牛刀）

# 3.二值信号量
## 简介
二值信号量是一种特殊的信号量，它的值只能为0或1。这个值表示资源的可用状态，可以用于多个线程对一个资源的访问。

二值信号量通常用于任务间的同步和互斥。你可以将它看作是只有一个队列项的队列，这个特殊队列只有两种情况：满的或者空的。当信号量为满时，表示资源可用；当信号量为空时，表示资源不可用。

在FreeRTOS中，二值信号量可以通过`xSemaphoreCreateBinary`函数创建。当一个任务需要使用某个资源时，它会尝试获取这个二值信号量。如果信号量为满，那么这个任务可以使用资源，并将信号量设置为空。如果信号量为空，那么这个任务会被阻塞，直到信号量变为满。
## 相关函数
| 函数                               | 描述         |
| -------------------------------- | ---------- |
| *xSemaphoreCreateBinary()*       | 动态创建二值信号量  |
| *xSemaphoreCreateBinaryStatic()* | 静态创建二值信号量  |
| *xSemaphoreGive()*               | 任务级释放二值信号量 |
| *xSemaphoreGiveFromISR()*        | 中断级释放信号量   |
| *xSemaphoreTake()*               | 任务级获取信号量   |
| *xSemaphoreTakeFromISR()*        | 中断级获取信号量   |
| *vSemaphoreDelete()*             | 删除信号量      |


# 4.计数信号量
## 简介
计数信号量是一种特殊类型的信号量，它的值可以大于1。计数信号量的主要用途有两个：
1. 事件计数：每次事件发生时，事件处理函数会释放计数信号量（即信号量的值加1）。其他任务会获取信号量（即信号量的值减1）来处理这些事件。因此，计数信号量的值实际上反映了事件发生的数量和事件处理的数量之间的差值。
2. 资源管理：计数信号量也用于表示有效资源的数量。任务在获取资源之前必须先获取计数信号量，以确保有足够的资源可供使用。当任务使用完资源后，会释放计数信号量，使得其他任务能够获取并使用这些资源。
## 相关函数

| 函数                                 | 描述              |
| ---------------------------------- | --------------- |
| *xSemaphoreCreateCounting()*       | 使用动态方法创建计数型信号量。 |
| *xSemaphoreCreateCountingStatic()* | 使用静态方法创建计数型信号量  |
| *uxSemaphoreGetCount()*            | 获取信号量的计数值       |
> **计数型信号量的释放和获取与二值信号量相同 ！**(毕竟都是信号量)


# 5.优先级翻转
## 简介

> [!不希望发生的BUG] 
> 优先级翻转是一个在实时操作系统中可能出现的问题，特别是在多任务环境中。

高优先级任务被低优先级任务阻塞，导致高优先级任务迟迟得不到调度。但其他中等优先级的任务却能抢到CPU资源。从现象上看，就像是中优先级的任务比高优先级任务具有更高的优先权（即优先级翻转）


# 6.互斥信号量
## 简介
为了解决优先级翻转问题。互斥信号量是包含优先级继承机制的二进制信号量。
当低优先级任务持有高优先级任务所需的资源时，将低优先级任务的优先级提升到高优先级任务的优先级，以确保高优先级任务能够及时执行。

## 相关函数
| 函数                              | 描述             |
| ------------------------------- | -------------- |
| *xSemaphoreCreateMutex()*       | 使用动态方法创建互斥信号量。 |
| *xSemaphoreCreateMutexStatic()* | 使用静态方法创建互斥信号量。 |
不能在中断中使用互斥信号量（毕竟中断没有任务优先级）
