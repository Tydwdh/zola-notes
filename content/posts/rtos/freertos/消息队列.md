# 简介
消息队列，是一种用于任务与任务间、中断和任务间传递一条或多条信息的数据结构，实现了任务接收来自其他任务或中断的不固定或固定长度的消息。

# 特点
- *FIFO顺序*：先进先出，先发送的消息会被先接收
- *线程安全*：队列操作是原子的，确保在多任务环境中的数据完整性
- *阻塞和非阻塞*：任务可以通过阻塞或非阻塞的方式发送和接收消息，如果任务队列满了或者为空，任务可以选择等待或者立即返回
- *优先级继承*：FreeRTOS支持基于优先级的消息传递，确保高优先级的任务在队列操作期间不会被低优先级任务阻塞
- *可变长度项*：队列中的项可以是不同长度的数据块，而不是固定大小

# **相关API函数**
## 1.创建队列

|          函数          |     描述     |
|:----------------------:|:------------:|
|    *xQueueCreate()*    | 动态创建队列 |
| *xQueueCreateStatic()* | 静态创建队列 |
## 2.写入队列
| 任务类型    | 函数名                          | 描述                                          |
| ------- | ---------------------------- | ------------------------------------------- |
| 任务级入列函数 | *xQueueSend()*               | 发送消息到队列尾部（后进入队列），这两个函数是一样的。                 |
|         | *xQueueSendToBack()*         | 同上                                          |
|         | *xQueueSendToFront()*        | 发送消息到队列头部（前进入队列）。                           |
|         | *xQueueOverwrite()*          | 发送消息到队列, 替换现有的消息, 当队列满了以后会覆盖最旧的消息,用于节省内存空间。 |
| 中断级入列函数 | *xQueueSendFromISR()*        | 发送消息到队列尾部（后进入队列），这两个函数是一样的，用于中断服务子程序使用。     |
|         | *xQueueSendToBackFromISR()*  | 同上                                          |
|         | *xQueueSendToFrontFromISR()* | 发送消息到队里头部（前进入对了），用于中断服务子程序使用。               |
|         | *xQueueOverwriteFromISR()*   | 发送消息到对了，替换现有的信息，当对了满了以后会覆盖最旧的信息，用于节省内存空间。   |

## 3.读取队列

| 分类      | 函数                       | 描述                  |
| ------- | ------------------------ | ------------------- |
| 任务级出队函数 | *xQueueReceive()*        | 从队列中读取队列项(消息), 并且移除 |
|         | *xQueuePeek()*           | 从队列中读取队列项(消息), 并且保留 |
| 中断级出队函数 | *xQueueReceiveFromISR()* | 从队列中读取队列项(消息), 并且移除 |
|         | *xQueuePeekFromISR ()*   | 从队列中读取队列项(消息), 并且保留 |


# 错误反省
今天遇到一个非常奇怪的bug，先看代码
```c
void vtask1(void *pvParameters)
{
    int i = 0;
    Key_Flag flag;
    while (1)
    {
        xQueuePeek(hkeyqueue, &flag, portMAX_DELAY);
        if (flag == Key_Flag_Single_Press)
        {
            xQueueReceive(hkeyqueue, &flag, 0);
            taskENTER_CRITICAL();
            OLED_SetCursor(1, 1);
            printf("%d", i++);
            taskEXIT_CRITICAL();
            flag = Key_Flag_None;
        }
    }
}
```
只是一个很简单的检测到按键信号就计数加1，但是每当`xQueueReceive`执行后就会导致i=0。
但是并没有看到对i的操作，猜测是对地址的操作。
在`xQueueReceive`中有这样一段代码
```c
 ( void ) memcpy( ( void * ) pvBuffer, ( void * ) pxQueue->u.xQueue.pcReadFrom, ( size_t ) pxQueue->uxItemSize ); 
```
当`pvBuffer`的大小小于队列中每个数据的大小，就会发生错误，会导致`flag`前面的变量被覆盖。
我当时创建队列使用的是
```c
hkeyqueue = xQueueCreate(3, sizeof(uint32_t));
```
我犯了一个错误，我默认以为枚举enum类型是32位的，但其实枚举类型是根据枚举中最大的那个数而发生变化 的，所以应该使用
```c
hkeyqueue = xQueueCreate(3, sizeof(Key_Flag));
```
