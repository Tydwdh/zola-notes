# FreeRTOSConfig.h文件的必要修改
默认配置中freertos分配了17k堆地址（stm32f103c8t6中ram只有20k），建议修改为10k
`#define configTOTAL_HEAP_SIZE       ( ( size_t ) ( 10 * 1024 ) )`

# 示例代码
```c
//任务句柄
TaskHandle_t task_handle;
//创建启动任务
    xTaskCreate(
        start_task,
        "start_task",
        TASK_STACK_SIZE,
        NULL,
        TASK_PRIORITY,
        &task_handle);
```
