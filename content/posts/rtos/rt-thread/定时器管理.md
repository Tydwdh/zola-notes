### 定时器管理

#### 1. 概述

RT-Thread的定时器提供两类定时器机制：

- ​**单次触发定时器**​：启动后只触发一次事件，然后自动停止
- ​**周期触发定时器**​：周期性触发事件，直到手动停止

根据执行环境分为：

- ​**硬件定时器**​(RT_TIMER_FLAG_HARD_TIMER)：在中断上下文中执行
- ​**软件定时器**​(RT_TIMER_FLAG_SOFT_TIMER)：在定时器线程上下文中执行

#### 2. 核心数据结构

```c
struct rt_timer;        // 定时器控制块
typedef struct rt_timer *rt_timer_t; // 定时器句柄类型
```

#### 3. 标志宏定义

| 宏定义                       | 值   | 说明             |
| ------------------------- | --- | -------------- |
| RT_TIMER_FLAG_DEACTIVATED | 0x0 | 定时器未激活         |
| RT_TIMER_FLAG_ACTIVATED   | 0x1 | 定时器已激活         |
| RT_TIMER_FLAG_ONE_SHOT    | 0x0 | 一次性定时器         |
| RT_TIMER_FLAG_PERIODIC    | 0x2 | 周期性定时器         |
| RT_TIMER_FLAG_HARD_TIMER  | 0x0 | 硬件定时器（中断上下文执行） |
| RT_TIMER_FLAG_SOFT_TIMER  | 0x4 | 软件定时器（线程上下文执行） |

#### 4. 控制命令

| 命令   | 宏定义                        | 说明        |
| ---- | -------------------------- | --------- |
| 设置时间 | RT_TIMER_CTRL_SET_TIME     | 设置定时器超时时间 |
| 获取时间 | RT_TIMER_CTRL_GET_TIME     | 获取定时器剩余时间 |
| 设为单次 | RT_TIMER_CTRL_SET_ONESHOT  | 更改为一次性定时器 |
| 设为周期 | RT_TIMER_CTRL_SET_PERIODIC | 更改为周期性定时器 |

#### 5. 定时器管理函数

##### 5.1 初始化定时器（静态创建）

```c
void rt_timer_init(rt_timer_t timer,         // 定时器句柄
                   const char *name,         // 定时器名称
                   void (*timeout)(void *),  // 超时回调函数
                   void *parameter,          // 回调参数
                   rt_tick_t time,           // 超时时间（tick）
                   rt_uint8_t flag);         // 标志位组合
```

​**特点**​：

- 初始化静态定时器对象
- 标志位组合示例：`RT_TIMER_FLAG_PERIODIC | RT_TIMER_FLAG_SOFT_TIMER`

##### 5.2 创建定时器（动态创建）

```c
rt_timer_t rt_timer_create(const char *name,
                           void (*timeout)(void *),
                           void *parameter,
                           rt_tick_t time,
                           rt_uint8_t flag);
```

​**特点**​：

- 从内存堆动态分配控制块
- 成功返回定时器句柄，失败返回RT_NULL

##### 5.3 定时器启停控制

```c
rt_err_t rt_timer_start(rt_timer_t timer);  // 启动定时器
rt_err_t rt_timer_stop(rt_timer_t timer);   // 停止定时器
```

​**注意事项**​：

- 定时器创建/初始化后需显式启动
- 周期性定时器停止前会持续触发

##### 5.4 定时器生命周期管理

```c
rt_err_t rt_timer_detach(rt_timer_t timer);  // 脱离静态定时器
rt_err_t rt_timer_delete(rt_timer_t timer);  // 删除动态定时器
```

​**重要区别**​：

- `detach`用于`rt_timer_init`创建的定时器
- `delete`用于`rt_timer_create`创建的定时器

##### 5.5 定时器控制

```c
rt_err_t rt_timer_control(rt_timer_t timer,
                          int cmd,
                          void *arg);
```

​**支持操作**​：

- 修改定时器类型（单次/周期）
- 查询/设置超时时间
- 命令参数参考第4节控制命令

#### 6. 使用示例

##### 6.1 静态定时器创建

```c
struct rt_timer my_timer;

void timeout_cb(void *param) {
    rt_kprintf("Timer expired! Param: %d\n", *(int*)param);
}

void timer_demo() {
    int param = 1234;
    // 创建100tick周期的软件定时器
    rt_timer_init(&my_timer, "mytimer", timeout_cb, &param,
                  100, RT_TIMER_FLAG_PERIODIC | RT_TIMER_FLAG_SOFT_TIMER);
    
    rt_timer_start(&my_timer);  // 必须显式启动
}
```

##### 6.2 动态定时器创建

```c
void timeout_cb(void *param) {
    rt_kprintf("One-shot timer triggered\n");
}

void timer_demo() {
    // 创建500ms单次硬件定时器
    rt_timer_t timer = rt_timer_create("oneshot", timeout_cb, RT_NULL,
                                       rt_tick_from_millisecond(500),
                                       RT_TIMER_FLAG_ONE_SHOT | RT_TIMER_FLAG_HARD_TIMER);
    
    if(timer != RT_NULL) {
        rt_timer_start(timer);
        
        // 运行一段时间后删除
        rt_thread_mdelay(1000);
        rt_timer_delete(timer);
    }
}
```

##### 6.3 定时器控制示例

```c
void control_demo(rt_timer_t timer) {
    rt_tick_t remaining;
    
    // 获取剩余时间
    rt_timer_control(timer, RT_TIMER_CTRL_GET_TIME, &remaining);
    rt_kprintf("Remaining ticks: %d\n", remaining);
    
    // 修改为200tick周期的定时器
    rt_timer_control(timer, RT_TIMER_CTRL_SET_PERIODIC, RT_NULL);
    rt_timer_control(timer, RT_TIMER_CTRL_SET_TIME, (void*)200);
}
```
