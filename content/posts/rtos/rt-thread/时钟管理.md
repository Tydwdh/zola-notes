### 时钟管理

#### 1. 概述

RT-Thread的时钟管理系统基于时钟节拍（OS Tick），提供以下核心功能：

- 获取当前系统时钟节拍值
- 设置系统时钟节拍值
- 增加系统时钟节拍值
- 时间单位转换（毫秒↔节拍）

​**关键概念**​：

- ​**时钟节拍**​：周期性硬件定时器两次中断间的间隔时间长度
- ​**系统时间**​：系统启动开始计数的时钟节拍数
- ​**节拍长度**​：由`RT_TICK_PER_SECOND`定义（单位：秒），如100Hz时每节拍为10ms

#### 2. 函数接口

##### 2.1 获取系统节拍

```c
rt_tick_t rt_tick_get(void);
```

​**功能**​：返回自系统启动以来的时钟节拍计数值  
​**返回值**​：32位无符号整数表示当前节拍数  
​**应用场景**​：高精度时间测量、超时判断  
​**示例**​：

```c
rt_tick_t start = rt_tick_get();
// 执行某些操作
rt_tick_t duration = rt_tick_get() - start;
```

##### 2.2 设置系统节拍

```c
void rt_tick_set(rt_tick_t tick);
```

​**功能**​：直接设置系统时钟节拍计数值  
​**适用场景**​：

- 系统时间校准
- 模拟时间流逝（测试场景）
- 时间同步

​**注意事项**​：

- 需谨慎使用，避免破坏系统时间连续性
- 通常仅在初始化或特殊场景下使用

##### 2.3 增加系统节拍

```c
void rt_tick_increase(void);
```

​**功能**​：通知内核经过一个系统时钟周期（通常在时钟中断服务例程中调用）  
​**执行流程**​：

1. 系统节拍计数器+1
2. 检查线程延时
3. 检查定时器超时

​**调用位置**​：硬件定时器中断服务程序（需用户实现）

##### 2.4 时间单位转换

```c
int rt_tick_from_millisecond(rt_int32_t ms);
```

​**功能**​：将毫秒时间转换为系统时钟节拍数  
​**参数**​：

- ​**ms**​：毫秒时间（允许范围：-1 ~ 0x7FFFFFFF）
    - `负数`：永远等待
    - `0`：不等待立即返回
    - `最大值`：0x7FFFFFFF（约24.85天）

​**返回值**​：对应的系统节拍数

#### 3. 使用示例

##### 3.1 精确延时实现

```c
void precise_delay(rt_int32_t ms) {
    rt_tick_t start_tick = rt_tick_get();
    rt_tick_t delay_ticks = rt_tick_from_millisecond(ms);
    
    while ((rt_tick_get() - start_tick) < delay_ticks) {
        // 主动让出CPU（非必须）
        rt_thread_yield();
    }
}
```

##### 3.2 超时检测

```c
#define TIMEOUT_MS 2000

rt_bool_t wait_for_event(void) {
    rt_tick_t start = rt_tick_get();
    
    while (!event_occurred()) {
        if (rt_tick_get() - start > rt_tick_from_millisecond(TIMEOUT_MS)) {
            rt_kprintf("Operation timeout!\n");
            return RT_FALSE;
        }
        rt_thread_mdelay(10);
    }
    return RT_TRUE;
}
```

##### 3.3 时钟中断处理

```c
void SysTick_Handler(void) {
    /* 增加系统时钟节拍 */
    rt_tick_increase();
}

void timer_init(void) {
    // 配置硬件定时器为RT_TICK_PER_SECOND频率
    // ...
    HAL_NVIC_SetPriority(SysTick_IRQn, 0, 0);
}
```


#### 4. 配置选项

| 配置宏                      | 默认值 | 说明        |
| ------------------------ | --- | --------- |
| RT_TICK_PER_SECOND       | 100 | 每秒节拍数（Hz） |
| RT_TIMER_TICK_PER_SECOND | 100 | 定时器节拍频率   |
| RT_USING_HWTIMER         | 禁用  | 启用硬件定时器支持 |

​**建议**​：

- 实时性要求高：设置1000Hz（1ms分辨率）
- 低功耗场景：设置10-100Hz减少中断次数
