#### 1. 概述

RT-Thread提供多种动态内存管理算法满足不同应用场景：

- ​**小堆内存管理**​：适用于资源受限系统（<2MB内存）
- ​**SLAB内存管理**​：适用于资源丰富系统，提供快速分配
- ​**MemHeap内存管理**​：支持合并多个物理内存区域形成统一内存堆

​**算法选择**​：

|算法|适用场景|特点|
|---|---|---|
|小堆|资源受限MCU|内存占用小，支持内存碎片整理|
|SLAB|嵌入式Linux兼容|快速分配，减少碎片|
|MemHeap|多内存区域系统|统一管理不连续物理内存|

#### 2. 核心数据结构

##### 2.1 内存堆管理控制块

```c
struct rt_memheap_item {
    rt_uint32_t magic;              // 魔数标识
    rt_size_t   pool_ptr;           // 指向内存池
    rt_size_t   next;               // 指向下一个内存块
    rt_size_t   prev;               // 指向上一个内存块
    rt_size_t   next_free;          // 指向空闲链表中下一个块
    rt_size_t   prev_free;          // 指向空闲链表中上一个块
};
```

##### 2.2 内存堆控制块

```c
struct rt_memheap {
    struct rt_object parent;        // 继承自内核对象
    void            *start_addr;    // 堆起始地址
    rt_uint32_t      pool_size;     // 堆大小
    rt_uint32_t      available_size;// 可用大小
    rt_uint32_t      max_used_size; // 历史最大使用量
    struct rt_memheap_item *block_list; // 内存块链表
};
```

#### 3. 通用内存管理函数

以下函数接口在所有内存管理算法中通用：

##### 3.1 内存分配

```c
void *rt_malloc(rt_size_t size);
```

​**功能**​：分配指定大小的内存块  
​**参数**​：`size` - 请求分配的字节数  
​**返回值**​：

- 成功：分配的内存块首地址
- 失败：`RT_NULL`

##### 3.2 内存重新分配

```c
void *rt_realloc(void *rmem, rt_size_t newsize);
```

​**功能**​：调整已分配内存块大小  
​**参数**​：

- `rmem`：已分配内存块指针
- `newsize`：新请求大小  
    ​**特性**​：
- 扩大内存：保留原数据
- 缩小内存：截断多余部分
- 特殊处理：`rmem`为`RT_NULL`时等同`rt_malloc`

##### 3.3 清零分配

```c
void *rt_calloc(rt_size_t count, rt_size_t size);
```

​**功能**​：分配并清零多元素内存块  
​**参数**​：

- `count`：元素数量
- `size`：单个元素大小  
    ​**计算公式**​：总大小 = count × size  
    ​**特性**​：分配的内存区域初始化为0

##### 3.4 内存释放

```c
void rt_free(void *rmem);
```

​**功能**​：释放已分配内存块  
​**参数**​：`rmem` - 由`rt_malloc`等函数返回的指针  
​**重要规则**​：

- 只能释放动态分配的内存
- 禁止多次释放同一内存块
- 禁止释放栈内存或静态内存

#### 4. MemHeap多内存堆管理

##### 4.1 内存堆初始化

```c
rt_err_t rt_memheap_init(struct rt_memheap *memheap,
                         const char *name,
                         void *start_addr,
                         rt_uint32_t size);
```

​**功能**​：初始化物理内存区域为内存堆  
​**参数**​：

- `memheap`：内存堆控制块
- `name`：内存堆名称
- `start_addr`：物理内存起始地址
- `size`：内存区域大小  
    ​**返回值**​：`RT_EOK`表示成功

##### 4.2 多内存堆使用流程

1. ​**初始化各物理区域**​：
    
    ```c
    /* 区域1: SRAM */
    rt_memheap_init(&sram_heap, "sram", (void*)0x20000000, 64 * 1024);
    
    /* 区域2: PSRAM */
    rt_memheap_init(&psram_heap, "psram", (void*)0x60000000, 4 * 1024 * 1024);
    ```
    
2. ​**自动合并管理**​：
    - 所有初始化内存堆加入统一管理
    - `rt_malloc`自动选择合适区域分配
3. ​**内存回收管理**​：
    - `rt_free`自动返回对应内存堆
    - 无需关注内存物理来源

#### 5. 使用示例

##### 5.1 基础内存分配

```c
void mem_demo(void) {
    // 分配100字节内存
    char *buffer = (char*)rt_malloc(100);
    if (buffer) {
        // 使用内存...
        rt_memset(buffer, 0, 100);
        
        // 重新调整为200字节
        char *new_buf = rt_realloc(buffer, 200);
        if (new_buf) {
            buffer = new_buf;
            // 使用扩展后的内存...
        }
        
        // 释放内存
        rt_free(buffer);
    }
    
    // 分配并清零数组
    int *array = (int*)rt_calloc(50, sizeof(int));
    if (array) {
        // 使用初始化为0的数组...
        rt_free(array);
    }
}
```

##### 5.2 多内存堆集成

```c
/* 定义不同物理内存区域的控制块 */
struct rt_memheap sram_heap;
struct rt_memheap sdram_heap;

void system_init(void) {
    // 初始化内部SRAM区域(64KB)
    rt_memheap_init(&sram_heap, "sram", (void*)0x20000000, 64 * 1024);
    
    // 初始化外部SDRAM区域(8MB)
    rt_memheap_init(&sdram_heap, "sdram", (void*)0xC0000000, 8 * 1024 * 1024);
    
    // 此后rt_malloc将自动在两个区域分配
}

void alloc_test(void) {
    // 分配小对象（可能在SRAM）
    void *small = rt_malloc(256);
    
    // 分配大对象（自动使用SDRAM）
    void *large = rt_malloc(2 * 1024 * 1024);
    
    // 释放时不需指定来源
    if(small) rt_free(small);
    if(large) rt_free(large);
}
```

#### 6. 最佳实践

1. ​**分配策略**​：
    
    ```c
    // 最佳分配尺寸（避免内部碎片）
    #define ALLOC_SIZE(size) (((size) + 7) & ~7)
    
    void *mem = rt_malloc(ALLOC_SIZE(100));
    ```
    
2. ​**内存泄漏检测**​：
    
    ```c
    #ifdef RT_DEBUG_MEMHEAP
    #define MEM_TRACE() rt_kprintf("[%s] Alloc at %s:%d\n", \
                                 __FUNCTION__, __FILE__, __LINE__)
    #else
    #define MEM_TRACE()
    #endif
    
    void *safe_malloc(size_t size) {
        void *p = rt_malloc(size);
        if(p) MEM_TRACE();
        return p;
    }
    ```
    
3. ​**内存池替代方案**​：
    
    - 频繁分配释放固定大小对象时
    - 使用内存池代替通用内存分配
4. ​**关键注意事项**​：
    
    - ​**禁止在中断中释放大内存块**​
    - 分配失败时必须有错误处理
    - 确保malloc/free成对出现
    - 定期检查`rt_memory_info()`监控内存使用

#### 7. 内存信息查询

```c
void rt_memory_info(rt_uint32_t *total, 
                    rt_uint32_t *used, 
                    rt_uint32_t *max_used);
```

​**功能**​：获取系统内存使用情况  
​**输出**​：

- `total`：内存总量
- `used`：当前使用量
- `max_used`：历史峰值使用量  
    ​**使用示例**​：

```c
rt_uint32_t total, used, max;
rt_memory_info(&total, &used, &max);
rt_kprintf("Memory: %d/%d KB (Peak: %d KB)\n", 
           used/1024, total/1024, max/1024);
```
