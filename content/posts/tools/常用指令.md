## 1. 分级标题
在Markdown中，你可以使用`#`来创建标题。例如：

```
# 一级标题
## 二级标题
### 三级标题
#### 四级标题
##### 五级标题
###### 六级标题
```

## 2. 段落
在Markdown中，段落是由一个或多个连续的文本行组成，它的前后要有一个以上的空行。

例如：
```
这是一个段落。

这是另一个段落。
```

## 3. 分割线

你可以在一行中用三个或更多的星号、减号、底线来建立一个分隔线，行内不能有其他东西。你也可以在星号或是减号中间插入空格。

例如：

```
***
---
___
```
___
## 4. 列表

- 无序列表：在每一行前面添加一个破折号（`-`）、星号（`*`）或加号（`+`）。例如：

```
- 列表项1
- 列表项2
- 列表项3
```

- 有序列表：在每一行前面添加数字和一个点（`.`）。例如：

```
1. 列表项1
2. 列表项2
3. 列表项3
```

## 5. 引用

在Markdown中，你可以使用`>`符号来创建引用。例如：
> 这是一个引用。

```
> 这是一个引用。
```

## 6. 强调

- **粗体**：使用两个星号（`**`）或下划线（`__`）包围文本。例如：`**粗体文本**` 或 `__粗体文本__`
- _斜体_：使用一个星号（`*`）或下划线（`_`）包围文本。例如：`*斜体文本*` 或 `_斜体文本_`
- ~~删除线~~：使用两个波浪线（`~~`）包围文本。例如：`~~删除线文本~~`

## 7. 下滑线

辅助线可以通过插入HTML `<ins>` 标签来创建。

例如：<ins>这是一个下划线</ins>

```
<ins>这是一个下划线</ins>
```

## 8. 字体字号

Markdown本身不支持修改字体和字号，但你可以通过插入HTML代码来实现。

例如：

```markdown

#### 使用 `<font>` 标签的修改字体

这里是默认字体

<font face="SimHei">这里是黑体</font>

<font face="KaiTi">这里是楷体</font>

这里是默认正文字号

<font size="1">1号字 最小</font>

<font size="2">2号字</font>

<font size="3">3号字 默认</font>

<font size="4">4号字</font>

<font size="5">5号字</font>

<font size="6">6号字</font>

<font size="7">7号字 最大</font>
```

## 9. 前景色，背景色
在 Markdown 文件中，建议使用 `<font>` 标签的 `color` 属性修改文字颜色。

**实例 1**：

```markdown
#### 使用 `style` 的标签的修改文字前景色

<font style="color: red">红色</font>
<font style="color: green">绿色</font>
<font style="color: blue">蓝色</font>

<font style="color: rgb(200,100,100)">使用 rgb 颜色值</font>

<font style="color: #FF00BB">使用十六进制颜色值</font>
```

## 10. 行内代码

你可以使用反引号（` `` `）来创建行内代码。例如：

`这是行内代码`

## 11. 代码块

你可以使用反引号（` `` `）来创建代码块。例如：

``` 这是一个代码块 ```

如果你想指定代码块的语言，可以在开始的反引号后面添加语言名称。例如：

```python 
hello_world(): print(“Hello, world!”)
```
## 12. 超链接

链接：使用方括号（[]）包围链接文字，紧接着用圆括号（()）包围URL。例如： [Bing](https://www.bing.com/)

## 13. 图片

复制粘贴即可
## 14. 任务列表

任务列表是一种特殊的列表，它的列表项包含了方括号和空格 `[]` 。如果方括号中放入字符 `x` ，表示该项已完成。

例如:

```
- [x] 已完成任务
- [ ] 未完成任务
```
- [ ] 已完成任务
- [ ] 未完成任务
## 15. 特殊符号

特殊字符打不出来

```
2*3*打不出来，必须加反斜号\
```

## 16. 注释

Markdown本身不支持注释，但你可以通过插入HTML注释来实现。

例如：<!-- 这是一个注释 -->

```
<!-- 这是一个注释 -->
```
